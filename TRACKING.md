# Gleiswerk Klickmessung

Dashboard: https://bentropic.goatcounter.com/

| Eintrag | Bedeutung |
|---|---|
| /gleiswerk-buecher/ | Seitenbesuche |
| amazon-eisenbahntechnik | Klicks auf Eisenbahntechnik in 60 Sekunden |
| amazon-gleise | Klicks auf Gleise verstehen in 60 Sekunden |
| amazon-eisenbahn-verstehen | Klicks auf Eisenbahn verstehen |

Die Button-Ereignisse verwenden die offizielle data-goatcounter-click-Einbindung. Keine zusätzlichen eigenen Click-Handler: dadurch keine doppelte Ereignisübertragung. Wiederholungen können von GoatCounter innerhalb einer Sitzung zusammengefasst werden; die Zahlen sind keine Rohzählung jedes einzelnen Klicks. Blockierte Skripte liefern keine Daten. Käufe bei Amazon werden nicht erfasst. Die Links funktionieren unabhängig vom Tracking weiter.
