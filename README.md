# Gleiswerk Buchempfehlung
Kurzer Buchnavigator für Zuschauer der Gleiswerk-Videos.

Öffentliche Seite: https://bentropic.github.io/gleiswerk-buecher/

## Amazon-Link ergänzen
In `books.json` unter `kurz.amazonUrl` den vollständigen Amazon-Link statt `null` eintragen. Der Kaufbutton ersetzt dann automatisch den Hinweis „Demnächst erhältlich“.

Statische HTML-Seite ohne Build-Schritt. GitHub Pages veröffentlicht den Hauptbranch direkt. Das Amazon-Badge stammt aus Amazons offiziellem deutschen Download, siehe https://affiliate-program.amazon.com/help/operating/amazonmarks/.
